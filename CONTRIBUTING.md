# Contributing to M-DOS DeX

Thank you for helping improve M-DOS DeX!

## Ways to contribute
- Report bugs and compatibility problems.
- Test the phone and Android TV apps.
- Improve the user interface.
- Add translations.
- Improve documentation.
- Submit code changes.

## Before submitting
1. Check existing issues.
2. Open an issue before large changes.
3. Fork the repository.
4. Create a separate branch for your work.
5. Submit a pull request with a clear explanation.

## Build

Requirements: JDK 17 and Gradle 8.9.

```bash
gradle --no-daemon assemblePhoneDebug assembleTvDebug
```

## Bug reports

Include:
- Device model
- Android version
- Phone or TV edition
- Steps to reproduce
- Expected and actual result

Never publish passwords, API keys or personal information.
